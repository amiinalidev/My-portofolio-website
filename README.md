## ⚙️ Getting Started

### Prerequisites

Just a web browser — no installations needed.

### Installation

1. Clone the repository:
```bash
   git clone https://github.com/amiinalidev/My-portofolio-website.git
```

2. Navigate to the project folder:
```bash
   cd My-portofolio-website
```

3. Open `index.html` in your browser.
